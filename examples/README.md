# Examples

These projects are minimal, runnable demonstrations of Test Automation
Reporting for GitHub Actions. Each example includes its test framework
configuration, representative tests, and a workflow that can be copied into a
project.

| Framework | Example |
| --- | --- |
| Playwright | [Playwright](playwright) |
| Jest | [Jest](jest) |
| Vitest | [Vitest](vitest) |
| pytest | [pytest](pytest) |
| Cypress | [Cypress](cypress) |
| JUnit 5 | [JUnit 5](junit5) |
| xUnit | [xUnit](xunit) |
| Cross-job reporting | [Cross-job workflow](cross-job) |

The repository's own CI runs the examples so dependency or integration changes
cannot silently leave the published instructions out of date.
